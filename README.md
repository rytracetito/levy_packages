# levy_packages

R packages for degradation models based on Lévy processes.

| Package | Content | Status |
|---|---|---|
| `levyfit` | Maximum likelihood estimation (Wiener, gamma, inverse Gaussian, variance-gamma, Meixner and inverse gamma processes) and inspection schedules | In progress |
| Simulation | Simulation of degradation trajectories | Planned |
| Goodness of fit | Goodness-of-fit tests for Lévy degradation processes | Planned |

## Installation

```r
devtools::install("levyfit")
```
